# 낚시 아케이드(가칭) — 전역 규칙 기획서 (세부 수치 제외)

Nov 12, 2026 · @뵤

## 1. 개요와 제약

이 게임은 제한 시간 안에 판단 입력으로 물고기를 잡아 점수를 겨루는, 한 판 5분 이내의 아케이드 낚시 게임이다. 0\~2단계에서 확정된 전역 규칙만 담았고, 세부 수치는 3단계에서 정한다.

| 항목 | 내용 |
| --- | --- |
| 장르·엔진 | 아케이드 미니게임, Unity 6 2D |
| 플랫폼·빌드 | PC 우선. 산출물은 exe / WebGL / Android 3종 (Android는 후순위) |
| 세계관 | 한국 고전(조선풍), 시대는 지정하지 않음 |
| 개발 제약 | 1인 개발, 하루 3시간. 기본 42h에서 청상아리를 Must로 올려 약 45h로 증액 (작성자 결정) |
| 에셋 | 무료 에셋 또는 임시 스프라이트 자체 제작 |
| 표기 규칙 | 표기 없음 = 확정 / **\[가정\]** = 작성자가 동의했으나 검증 전 / **\[수치 미정\]** = 3단계에서 확정 |

## 2. 디자인 필러

이 게임의 재미 가설은 "상황을 읽고 고르는 판단"과 "스킬 조합이 만드는 점수 경쟁"이다. 필러는 이 두 가지를 보호한다.

| 지킬 가치 | 기획 의도 |
| --- | --- |
| 읽고 고르는 판단 | 입질마다 그림자 크기와 물살을 보고 키를 고른다. 손 기술이 아니라 판단이 실력이 되어야 재미 가설 ①이 검증된다. |
| 5분 안에 끝나는 가벼움 | 스킬 선택부터 결과까지 한 호흡에 끝난다. "한 판 더"가 나오려면 한 판이 가볍워야 한다. |
| 빌드로 갈리는 점수 경쟁 | 스킬 3개 조합이 점수 전략을 바꾸고, 그 결과가 리더보드에서 비교된다. 재도전의 이유가 된다. |

| 하지 않을 것 | 기획 의도 |
| --- | --- |
| 타이밍 정밀도·연타 속도를 요구하지 않는다 (규칙 기반 입력만) | 모바일 대응이 쉽고 판단 요소가 흐려지지 않는다. |
| 장기 성장과 재화를 두지 않는다 | 판마다 같은 출발선이어야 리더보드가 공정하고, 2주 범위를 넘는다. |
| 콘텐츠 양으로 승부하지 않는다 (어종·맵·스킬 가짓수 확장) | 10종 안에서 선택이 의미 있게 갈리는 쪽이 가설 검증에 유리하다. |

## 3. 코어 루프

루프는 "한 번의 낚시(약 5초 단위) → 한 판 → 재도전"의 세 단위로 돌아가며, 각 단위마다 플레이어의 선택과 즉각적인 피드백이 있다.

| 단위 | 흐름 | 플레이어 선택 | 피드백 |
| --- | --- | --- | --- |
| 한 번의 낚시 | 캐스팅(자동) → 입질 대기 → 입질 → 판단 키 입력 → 확정 → 결과 | 물살용 키와 어종용 키를 고른다. 틀렸다 싶으면 시간 안에 다시 입력해 정정한다. 지금 확정할지 지연할지도 정한다. | 그림자·물살 표시, 입력 큐 2칸, 제한 시간 게이지, 성공/실패 연출, 점수 팝업, 피버 게이지 |
| 한 판 (5분 이내) | 스킬 3개 선택 → 본편 → 종료 → 결과 → 리더보드 등록 | 사전에 빌드를 고른다. 본편에서는 피버 진입 시점을 조절한다. | 타이머, 누적 점수, 피버 연출, 청상아리 진행도, 결과 화면 |
| 반복 세션 | 재도전 | 같은 빌드로 다시 할지, 스킬 3개를 바꿀지 정한다. | 리더보드 순위 변동, 내 최고 기록, 만선 문구, 청상아리 달성 여부 |

## 4. 낚시 조작·판정 규칙

플레이어는 입질마다 판단 키 3종으로 물살과 어종을 순서대로 입력하고, 확정 키로 판정을 요청한다. 판정은 확정 시점의 입력 큐로 결정된다.

- **입력:** 판단 키 3종(강력 / 섬세 / 무난)과 확정 키(낚아올리기). 버튼은 마우스·터치·키보드 단축키 공용이다.
- **입력 큐 2칸:** 판단 키를 3번째로 누르면 가장 오래된 입력이 밀려난다. 확정 시점의 큐에서 **1번 = 물살 판단, 2번 = 어종 판단**으로 읽는다. 예: 물살 강, 어종 중이면 `강력 → 무난 → 낚아올리기`.
- **제한 시간 n초:** 입질 시작부터 n초 안에 확정하지 못하면 즉시 실패한다 \[수치 미정\].
- **판정 기준:** 물살은 **확정 시점의 물살**로 판정한다. 어종은 입질 시 그림자 크기로 추정한다.
- **판정 결과:** 키별 정답 여부를 합쳐 성공률 3단계(맞은 키 0 / 1 / 2개 기준)로 변환한 뒤 성공 여부를 뽑는다 \[수치 미정\].
- **확정 조건:** 큐가 2칸 미만일 경우 확정키를 입력하면 물살 조건만 정답을 판정하고 어종은 오답으로 처리한다.
- **구조:** 판정은 "입력 → 결과"를 내는 독립 모듈로 둔다.&#32;

| 판단 | 강력 | 섬세 | 무난 |
| --- | --- | --- | --- |
| 물살 | 강 | 약 | 보통 |
| 어종 | 대형 정답 | 소형 정답 | 중형 정답, 소형은 부분 정답(안전한 대체) |

## 5. 어종·입질·물살

판단의 재료는 그림자 크기와 물살 두 가지뿐이고, 어종은 대 2 / 중 3 / 소 5 = 10종이다.

| 항목 | 규칙 |
| --- | --- |
| 어종 구성 | 대형 2종, 중형 3종, 소형 5종. 종별 점수·출현 확률·난이도 \[수치 미정\] |
| 그림자 힌트 | 입질 시 크기(대/중/소)만 그림자로 노출하고 종은 숨긴다. 중/소 구분의 모호한 정도는 고정 설계값 \[수치 미정\] |
| 입질 대기 | 캐스팅 후 입질까지 최소\~최대 시간 안에서 랜덤. 최소\~최대 범위는 물고기 크기(대/중/소)별로 다르다. 스킬 5는 이 수치에 ×1.n, 스킬 6은 ×0.n을 고한다 \[수치 미정\] |
| 판단 제한 시간 n | 입질마다 재충전. 입질 대기 시간과는 별개다. |
| 물살 | 강 / 보통 / 약 3단계. **일정 구간마다 변경**된다. 스킬 9가 변경 빈도를 올린다. 판정은 확정 시점의 물살 기준. |

## 6. 점수·피버·청상아리

점수는 어종 기본 점수에 피버 배수와 스킬 수정자를 곱해 누적하고, 실패해도 감점은 없다. 실패의 비용은 놓친 물고기와 소모된 시간이며, 별도의 경직 시간은 없다.

**점수**

- 점수 = 어종 기본 점수 × 피버 배수 × 스킬 수정자. 스킬 9는 성공 포획 시에만 고정 가점을 더한다.
- 승패는 없다. 상대 평가는 리더보드, 절대 기준은 "만선" 점수 문턱 하나다.

**피버**

- 게이지는 성공 포획으로 충전된다 (크기 비례 없이 성공포획 횟수 고정 수치). 가득 차면 **자동 진입**한다.
- 피버는 **고정 시간 D** 동안 진행된다. 점수 배수와 입질 빈도가 올라간다 (배수·빈도·D \[수치 미정\]).
- 피버 중에는 게이지를 획득할 수 없고, 피버가 끝나면 게이지가 초기화되어 다시 쌓는다.
- 라운드 시간이 끝나도 피버 중이면 게임이 종료되지 않고, **피버가 끝나는 즉시 종료**된다.

**타이밍 전략 (의도된 설계)**

진입이 자동이므로 플레이어는 게이지를 채우는 성공 포획의 확정 시점을 제한 시간 n 안에서 지연하거나, 일부러 실패하고 다음 입질을 노릴 수 있다. 라운드 말미에 피버를 배치하면 피버 시간 D가 라운드 시간에 추가로 얹히므로, "지금 쓸까, 한 번 더 쌓을까"가 판단 요소가 된다. 이 전략은 허용하고, 한계(진행 중인 입질 처리 등)는 3단계 예외 처리에서 정한다.

**청상아리**

- 판마다 랜덤으로 정해진 3종 조합을 **각 1회씩 포획**하면(순서 무관) 청상아리가 나타나고, 잡으면 최고점이다. 판당 1회 \[가정\].
- 기본 조합은 소·중·대 각 1종이고, 스킬 8을 장착하면 **대·대·중**으로 바뀐다\[추후 밸런싱 필요\].
- 조합 어종에는 스폰 가중치를 주지 않는다. 달성은 운의 영역이다.

## 7. 패시브 스킬 10종

플레이어는 라운드 전에 10종 중 3개를 고르고, 모두 패시브다. 스킬은 "무조건 이득"이 아니라 반드시 **조건**(특정 상황에서만 가치)이나 **대가**(다른 곳이 약해짐)를 가진다. 항상 정답인 스킬을 구조적으로 막기 위한 규칙이다.

| # | 스킬 \[가칭\] | 분류 | 효과 | 조건 / 대가 |
| --- | --- | --- | --- | --- |
| 1 | 큰 손 | 점수 | 대형 점수↑ | 조건: 대형 포획 |
| 2 | 알뜰 수확 | 점수 | 소형 점수↑ | 조건: 소형 포획 |
| 3 | 신바람 | 점수 | 피버 배수↑ | 조건: 피버 진입 |
| 4 | 불씨 | 시간 | 피버 게이지 획득↑ | 조건: 성공 포획 (피버 중 획득 불가) |
| 5 | 느긋한 낚시꾼 | 시간 | 판단 제한 시간↑ | 대가: 입질 대기 ×1.n \[가정\] |
| 6 | 재빠른 손 | 시간+출현 | 입질 대기 ×0.n | 대가: 소형 입질 확률 소폭↑ \
(소형 입질 증가폭 만큼 중, 대형 확률을 깎음) |
| 7 | 침착 | 확률 | 확률적으로 오답 무시 | 조건: 정답 2/2가 아닐 때, 확률 제한 |
| 8 | 묵직한 입질 | 출현 | 중형 이상 입질 확률 소폭↑ | 대가: 청상아리 조합이 대·대·중으로 변경\
&#91;밸런싱 필요\] |
| 9 | 물살 타기 | 점수 | 물살 입력 정답 시 소폭 고정 가점 | 대가: 물살이 자주 바뀜 |
| 10 | 큰물 욕심 | 위험 | 대형 출현비↑ | 대가: 판단 제한 시간↓ |

**대표 빌드 (3개 선택이 라운드 흐름을 바꾸는지 점검)**

| 빌드 | 구성 | 라운드 흐름 |
| --- | --- | --- |
| 안정형 | 5 + 7 + 2 | 실패를 줄이고 소형을 꾸준히 수확 |
| 피버 올인 | 3 + 4 + 6 | 피버 진입 빈도와 배수에 집중 |
| 대어 도박 | 10 + 1 + 7 | 대형 위주로 고점을 노림 |
| 소형 속사 | 2 + 6 + 9 | 횟수를 늘려 소형을 몰아 수확 (지배 후보) |

**재점검에서 나온 문제와 대응 (구조, 수치는 3단계)**

- **스킬 8이 청상아리에 의존한다:** 청상아리를 Must로 승격해 해소했다.
- **스킬 8의 대가가 효과에 상쇄될 수 있다:** (대·대·중)은 대형이 필요한데 8은 대형 입질을 올린다. 장착 시 청상아리 달성 확률이 기본보다 낮거나 같아야 한다는 설계 목표를 둔다. 8과 10을 함께 쓸 때의 대형 중복 가산에는 상한을 둔다.
- **소형 속사 빌드가 지배 후보다:** 2, 6, 9가 모두 횟수 비례로 유리하고, 고정 가점은 저가 어종일수록 상대 가치가 커진다. 소형 기대 점수/시간을 대어 도박 빌드보다 낮게 유지하고, 9번 가점에 소형 점수 대비 상한을 둔다.
- **피버 올인도 지배 후보다:** 피버 구간의 점수 비중 상한을 설계 목표로 둔다.
- **9번의 대가 실효성:** 확정 시점 물살 기준이어야 대가가 성립한다.
- **6번과 8번의 상쇄:** 소형↑과 중형 이상↑은 서로 상쇄된다. 선택의 방향이 갈리는 의도된 상충으로 허용한다.
- **성공률 보정 스킬이 7번 하나뿐이다:** 초보에게는 필수에 가깝고 숙련자에게는 가치가 줄어들 수 있다. 사용률 로그로 판단한다.

## 8. 라운드 진행과 엔딩

한 판은 스킬 선택부터 결과·등록까지 포함해 5분 이내여야 한다. 피버 지연 때문에 판 길이는 라운드 시간보다 최대 D만큼 늘어난다.

**흐름**

1. 타이틀
2. 스킬 3개 선택
3. 본편 (라운드 시간 T, 피버 진행 중이면 피버 종료까지)
4. 종료 문구 "오늘 고기잡이 종료!"
5. 결과 화면
6. 리더보드 등록 흐름 (조건 충족 시)
7. 재도전 또는 타이틀

**시간 제약:** 스킬 선택 + T + 피버 지연 D + 결과·등록 시간 ≤ 5분 \[수치 미정\].

**만선:** 일정 점수 이상이면 "만선이오!" 문구와 함께 결과 화면이 특수 연출로 교체된다. UI 구성은 동일하다. 특수 일러스트는 리소스 단계까지 결정을 보류하고, 없으면 문구와 간단한 연출로 대체한다. 만선 점수 문턱 \[수치 미정\]

**결과 화면**

- 점수 총합을 보여준다.
- 포획한 물고기 이미지 밑에 점수를 표기한 유닛을 바둑판 배열로 나열한다. 피버 배수 포획은 Xn.n까지 표기한다.
- 목록이 정해진 UI 영역을 넘으면 세로 스크롤로 넘기고 스크롤 영역은 숨긴다.
- 항목은 하나씩 나타나며, 마지막 줄에 추가될 때는 스크롤을 함께 내린다 (자동 스크롤 연출은 Should, 기본은 스크롤 영역만 구현).

## 9. 라운드 내 자원 (Source / Sink)

라운드 안의 자원은 일곱 가지이고, 점수만 Sink가 없어 단조 증가한다. 폭주와 정체는 Source 상한과 보상 곡선으로 막는다.

| 자원 | Source | Sink |
| --- | --- | --- |
| 라운드 시간 | 시작 시 고정값 T | 경과, 입질 대기 |
| 판단 제한 시간 n | 입질마다 재충전 | 경과 (0이면 실패) |
| 피버 게이지 | 성공 포획 | 피버 종료 시 초기화. 실패해도 감소 없음 |
| 피버 지속 | 게이지 가득 시 자동 진입 | 경과 (고정 D). 종료 시 게임 종료 가능 |
| 입력 큐 2칸 | 키 입력 | 밀림, 확정 후 비움&#32; |
| 점수 | 포획 (어종 × 피버 × 수정자) | 없음 (감점 없음) |
| 청상아리 진행도 | 목표 조합 어종 포획 | 달성 시 청상아리 출현 후 소멸 \[가정\] |

**폭주·정체 점검과 대응 방향 (수치는 3단계)**

- **후반 폭주:** 피버 + 신바람 + 청상아리가 겹치면 점수가 급증한다. 피버 중 게이지 획득 불가(확정)와 피버 구간 점수 비중 상한을 설계 목표로 둔다.
- **종료 직전 진입:** 피버 시간 D가 라운드 시간에 추가로 얹히는 것을 허용한다. 한 판 길이 상한(5분)에 D가 포함되어야 한다.
- **숙련자 정체:** 실패가 없는 플레이어는 시간 Sink가 입질 대기뿐이라 점수 차이가 작아진다. 변별력은 빌드 선택, 피버 타이밍, 청상아리 달성에서 나오게 하고, 스킬 5와 10의 대가로 압박을 보강한다.
- **초반 무보상:** 첫 피버까지의 보상 곡선이 평탄하지 않도록 첫 진입 임계값을 낮게 설계한다.

## 10. 리더보드·저장

리더보드는 Firebase REST(UnityWebRequest)로 붙이고, 계정·로그인 없이 닉네임과 점수만 다룬다. 조회 요청의 성공·실패를 연결 상태 판정으로 쓴다. exe, WebGL, Android 3종에서 같은 흐름이 동작하게 하기 위해서다.

&#91;embedded content: 리더보드 등록 흐름 · 판정 1개, 실패 분기 2개\]

조회 실패와 쓰기 실패는 같은 재시도/취소 UI로 처리하고, 취소하면 등록 없이 결과 화면에 남는다.

| 항목 | 규칙 |
| --- | --- |
| 저장 구조 | 고정 슬롯 N개. 등록은 빈 슬롯이나 최하위 슬롯에 덮어쓰기로 한다 (N \[수치 미정\]) |
| 쓰기 조건 | 보안 규칙으로 "새 점수 > 기존 점수"일 때만 쓰기 허용, 삭제 불가, 타입·범위 검증 |
| 등록 가능 조건 | 빈 슬롯이 있거나 **최하점 초과** (동점은 등록 불가) |
| 동점 처리 | 점수 내림차순 → 동점이면 먼저 달성한 기록 우선. 시각은 서버 타임스탬프 사용을 권장 |
| 닉네임 | 중복 허용, 표시용. 길이 제한 \[수치 미정\], 금칙어 필터는 Could |
| 로컬 저장 | 기기 내 최고점수 하나만 저장 |
| 네트워크 실패 | 재시도 / 취소 버튼을 제공. 취소하면 등록 없이 결과 화면에 머무른다. 랭킹 화면에서도 같은 처리, 취소 시 로컬 최고점수만 표시 |
| 동시 제출 | 같은 슬롯을 노린 늦은 쓰기는 실패한다. 재시도 UI로 처리한다. |

## 12. 미정 항목과 3단계 입력

이 문서의 전역 규칙은 확정됐지만, 아래 세 가지는 3단계에서 수치나 예외 처리로 마무리해야 한다.

**A. 수치로 정할 것**

- 어종 10종의 점수·출현 확률·난이도, 그림자 모호도
- 입질 대기 최소\~최대 (물고기 크기 대/중/소별), 판단 제한 시간 n, 물살 변경 주기
- 성공률 3단계, 스킬 5·6의 곱연산 배율
- 라운드 시간 T, 피버 고정 시간 D, 피버 배수, 게이지 임계값
- 스킬 10종의 효과 크기, 만선 점수 문턱, 리더보드 슬롯 수 N, 닉네임 길이
- 기준: 스킬 8 장착 시 청상아리 달성 확률 ≤ 기본, 점수 계열 3종의 기대 증분 동일

**B. 확인이 필요한 규칙**

1. 부분 정답 키(무난→소형)를 "맞은 키 개수"에 어떻게 합산할지
2. 청상아리 (대·대)가 서로 다른 어종(대형 2종 전부)인지
3. 피버 중 "출현 확률 상승"을 입질 대기 단축으로 구현할지
4. 어종별 "출현 조건"의 종류(물살 연동, 피버 연동 등)
5. 어종 크기별 피버 게이지 기여도

**C. 3단계 예외·악용 처리로 넘기는 것**

- 라운드 종료 시 진행 중인 입질 처리 (확정 지연 전략과의 관계)
- 일시정지·앱 전환, 시간 변조, 키 연타
- 리더보드 어뷰징 (점수 위조, 한 기기의 슬롯 독점)
- 스킬 8과 10의 대형 중복 가산, 피버 진입 시점 조작에 따른 시간 연장 한도

**D. \[가정\] 목록**

- 스킬 5의 대가는 입질 대기 ×1.n
- 청상아리는 판당 1회이며, 달성 시 출현 후 소멸한다
- 시간 예상치 전부 (문서 정리 3h는 AI 초안 제공을 전제로 한다)
